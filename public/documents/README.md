# Resume Document Directory

Place your official resume PDF here:
`Yogesh-R-Mehta-Resume.pdf`

The application checks for this file at runtime and links directly to:
`/Portofolio/documents/Yogesh-R-Mehta-Resume.pdf` (or `./documents/Yogesh-R-Mehta-Resume.pdf`).

When this file is present:
- The "Download Resume" buttons in the Hero, Navigation, and Footer will trigger a direct PDF download.
- The "View Resume" buttons will open the PDF in a new browser tab with fallback to the structured digital resume modal.
